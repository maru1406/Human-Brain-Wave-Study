Human Brain Wave Study using EEG and Deep Learning for Emotion Recognition

Project Abstract

Emotion recognition using electroencephalogram (EEG) signals has become an important research area in affective computing, healthcare, and human–computer interaction. Traditional emotion recognition approaches often rely on facial expressions, speech, or textual data, which may not accurately represent a person’s genuine emotional state. EEG-based emotion recognition provides a more reliable alternative by directly analyzing brain activity. The existing basepaper utilizes signal preprocessing, feature extraction techniques such as Power Spectral Density (PSD), Spectral Entropy (SE), and Hjorth parameters, followed by dimensionality reduction using Principal Component Analysis (PCA). The processed features are then classified using machine learning models including Gaussian Naïve Bayes, Support Vector Machine (SVM), Random Forest, and deep learning models such as Long Short-Term Memory (LSTM) and Gated Recurrent Unit (GRU), achieving an accuracy of up to 97%. To further enhance emotion classification performance, this work proposes an advanced hybrid model that integrates Multi-Scale Convolutional Neural Networks (CNN), Transformer architecture, Bidirectional Long Short-Term Memory (BiLSTM), and XGBoost. The Multi-Scale CNN is used to capture spatial and temporal patterns from EEG signals at different resolutions, while the Transformer module effectively models long-range dependencies within the EEG sequences. The BiLSTM layer learns bidirectional temporal relationships in the signal data, and XGBoost is employed as the final classifier to improve decision-making and classification accuracy. This hybrid architecture enables better feature representation and improves the robustness of the emotion recognition system. The proposed model is evaluated using the EEG Emotion dataset containing labeled emotional states such as positive, neutral, and negative. Experimental results demonstrate significant performance improvements over the existing system, achieving a final accuracy of 0.9929, with precision, recall, and F1-score values close to 0.99 across all emotion classes. The results indicate that the proposed hybrid framework provides a more accurate and reliable approach for EEG-based emotion recognition and can be effectively applied in intelligent healthcare systems, affective computing applications, and advanced human–computer interaction systems.
